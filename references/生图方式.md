# 生图方式：找不到自带工具时怎么办

SKILL.md 第零步没在你的工具里找到生图能力，就读这一份。回复用户时推荐一条，其余一句话带过，等他选：

- 你能执行命令、而且查到他电脑上装着能生图的工具（比如 `codex --version` 能跑通）→ 推荐第二条，最省他的事
- 他提过手上有某家的API → 推荐第一条
- 都不确定 → 推荐第三条，什么环境都能走

不管走哪条，后面的事都一样：角色设定图和精灵图落到当前工作目录，你接着跑第二步到第四步。

## 一、用户给一个图片生成API

用户有某家图片模型的API（火山方舟、OpenAI、阿里百炼……都行），让他告诉你用哪家、哪个模型，并把密钥放进环境变量或当前目录的 `.env`，**不要让他把密钥直接贴进对话**。

你按那家的官方文档写调用：模型名、参数名、怎么传参考图、支不支持透明背景，都以文档当时的写法为准，不要凭记忆写。写成一个小脚本放在工作目录，输入提示词、参考图路径、比例，输出PNG文件。先用一张图试通，再跑完整流程。

按量付费的接口，开跑前告诉用户大概要生成几张（一套8个表情＝1张设定图＋8张精灵图，加上返工），让他心里有数。

## 二、调用他电脑上的其他工具

你能执行命令、而用户电脑上装着带生图能力的工具时，可以把生成这一步交给它。比如装了 Codex 命令行（`codex --version` 能跑通），用非交互模式让它生成，它会调自己内置的生图，花的是用户 ChatGPT 订阅的额度：

```bash
codex exec --skip-git-repo-check -s workspace-write -C <工作目录> "用你的生图工具画一张图，保存为 <工作目录>/<文件名>.png。比例 16:9。参考图：<工作目录>/角色设定图.png。提示词：<提示词>"
```

参数以本机 `codex exec --help` 为准。一张图通常要几分钟。

注意：

- 先单独生成一张试通，确认文件真的落在你指定的位置、是这次新生成的（看修改时间、打开看内容），再批量做。工具报「成功」不等于文件对
- 每次只交给它一张图的任务，不要并行发好几个，生成的图容易对不上号
- 参考图用文件路径交给它，并在提示词里写清楚这张参考图的作用

## 三、用户自己去产品里生成，把图发回来

最通用的一条，什么环境都能走：你把每一步的提示词写好，用户拿去豆包、即梦、WorkBuddy 或任何他常用的生图产品里生成，下载后发给你（或放进工作目录）。

角色设定图的提示词单独先给，他发回来、确认像了，再把所有精灵图的提示词一次给全，编好号，让他照着一张张生成、按编号发回来。每条写清楚：

- 要传哪张图当参考（照片、原图，或者角色设定图）
- 比例选什么（精灵图按 SKILL.md 第三步的表选）
- 背景：用纯色背景那句，别让他去找「透明背景」选项、也不用他判断真假透明，切帧时脚本会处理

他说找不到某个设置，就照他看到的界面帮他找，或者换个能用的设置，不卡在这里。

用户发回来的图，你先看一遍再往下走：格数对不对、角色像不像、字有没有错。

## 判断一个工具能不能用

- **参考图**：照片起点和图片起点必须能传参考图；只有文字描述起点可以不传，但后面每张精灵图都要把角色描述写全（见 `定角色.md` 第三节）
- **透明背景**：能出真透明最好；不能就要纯色背景，切帧脚本会抠。生成后可以用一行代码检查是不是真透明：`python3 -c "from PIL import Image; import sys; a=Image.open(sys.argv[1]).convert('RGBA').getchannel('A'); print('真透明' if a.getextrema()[0] < 16 else '不透明')" 图.png`
- **比例**：16:9 最好用（4×2共8帧）；只有方图也能做（3×3共9帧）

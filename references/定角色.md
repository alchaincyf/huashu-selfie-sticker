# 定角色：三种起点，产出同一张角色设定图

不管从哪里开始，这一步的产出都是一张角色设定图：左边正面、侧面、背面三个全身站姿，右边几个头部特写表情。它是后面所有精灵图的唯一参考。

设定图的背景不用透明，后面只拿它当参考。工具能出透明就照提示词写透明背景；不能就把最后一句换成「背景是干净的浅灰色，不要出现任何文字」。

## 一、照片里的人

用户给的是自己（或某个人）的照片：正脸、五官清楚，最好有标志性的帽子、眼镜、发型。

参考图传照片，用这条提示词（括号里换成他自己的标志）：

```
参考图是一位{男生/女生}。把{他/她}画成一张Q版卡通贴纸角色设定图：左边是同一个角色的正面、侧面、背面三个全身站姿并排，右边是四个头部特写表情（开心大笑、震惊、无语翻白眼、得意坏笑）。保留{他/她}的标志：{帽子、眼镜、发型、常穿的衣服}，五官和脸型要像参考图里的{他/她}。三头身比例，粗黑描边，干净的平涂上色，表情包贴纸风格，每个形象外面有一圈白色贴纸描边。除了角色本身，其余全部是透明背景，不要出现任何文字。
```

不像就改提示词里的标志描述再出一张。用户想要别的画风（日漫、像素、黏土、水彩……），把「Q版卡通贴纸」和「三头身比例，粗黑描边，干净的平涂上色」换成那种画风的描述。

## 二、任意一张图

用户给的不是人像，先看这张图是什么，再决定怎么处理。拿不准用户想要哪种，用一句话问，同时给出你的建议。

**已经是一个角色**（手绘的小人、吉祥物、已有的卡通形象、他自己画的东西）：默认保留它本来的样子和画风，只是补全多个角度。

```
参考图是一个{简短描述，例如：手绘的蓝色小怪兽}。照着它画一张角色设定图：左边是同一个角色的正面、侧面、背面三个全身站姿并排，右边是四个头部特写表情（开心大笑、震惊、无语翻白眼、得意坏笑）。造型、比例、配色、线条和画风都和参考图保持一致，参考图里看不到的角度按同样的风格合理补全。除了角色本身，其余全部是透明背景，不要出现任何文字。
```

图不太好用（侧脸、糊、被挡住、一张图里好几只）时，告诉用户哪里不好、要一张什么样的；他没有更好的，就用这张做，并问清楚是图里哪一个、哪些特征要保留。

**宠物或动物照片**：默认画成Q版卡通，保留毛色、花纹、品种特征这些让主人一眼认出来的东西。

```
参考图是一只{品种和颜色，例如：橘白相间的猫}。把它画成一张Q版卡通贴纸角色设定图：左边是同一个角色的正面、侧面、背面三个全身站姿并排，右边是四个头部特写表情（开心、震惊、无语、得意）。保留它的{毛色、花纹、耳朵形状、项圈等标志}，要让主人一眼认出是它。粗黑描边，干净的平涂上色，表情包贴纸风格，每个形象外面有一圈白色贴纸描边。除了角色本身，其余全部是透明背景，不要出现任何文字。
```

**物品、食物、logo 这类没有脸的东西**：问用户是要给它加上眼睛嘴巴手脚变成角色（拟人化，最适合做表情），还是保持物品原样、只让它动（比如一杯奶茶晃来晃去）。拟人化就用上面「已经是一个角色」那条，把描述换成「把参考图里的{物品}拟人化成一个卡通角色，加上眼睛、嘴巴和小手小脚，保留它的形状和配色」；保持原样可以跳过设定图，直接用原图当参考进精灵图那一步。

## 三、什么图都没有

用户只说了想要什么（「一只上班摸鱼的柴犬」「一个会翻白眼的小番茄」），就按描述出设定图：

```
设计一个{角色描述}，画成一张卡通贴纸角色设定图：左边是同一个角色的正面、侧面、背面三个全身站姿并排，右边是四个头部特写表情（开心大笑、震惊、无语翻白眼、得意坏笑）。{外形、配色、标志性配饰}。粗黑描边，干净的平涂上色，表情包贴纸风格，每个形象外面有一圈白色贴纸描边。除了角色本身，其余全部是透明背景，不要出现任何文字。
```

描述太空（「随便做一个可爱的」），先给他3个方向，每个一句话，例如「戴耳机的熊猫程序员」「爱生气的小饺子」「什么都慢半拍的树懒」，他挑一个或者说自己的想法，再出图。

**生图工具不能传参考图时**（只有这种起点还能做），设定图出来后，把角色写成一段固定的角色描述：物种或身份、体型比例、每个部位的颜色、标志性配饰、画风。后面每张精灵图的提示词都把这段完整地贴进去，代替「参考图是……」那句。这样每张图之间的角色会有些出入，先跟用户说明。
